# SoLeaf `.github`

This repository holds SoLeaf LLP's organisation-wide GitHub files.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public introduction shown on [github.com/SoLeaf-LLP](https://github.com/SoLeaf-LLP) |
| [`SECURITY.md`](SECURITY.md) | How to report a security issue privately |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Outside contributions are not accepted |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expected behaviour in SoLeaf project spaces |
| [`SUPPORT.md`](SUPPORT.md) | Where to send enquiries |
| [`.github/`](.github) | Default issue and pull request templates |

GitHub applies these community health files to every SoLeaf repository that does not have its own version. A repository's own file always takes priority.

**Licences are not inherited.** Every SoLeaf repository must contain its own `LICENSE` file (the SoLeaf Proprietary License). The [`LICENSE`](LICENSE) here covers this repository only, including the SoLeaf logo and profile content.
